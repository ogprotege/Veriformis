## Exit gate

Every current capability claim resolves to code and passing evidence or is
explicitly labeled with a weaker evidence grade. Planned and candidate work is
not described as implemented. Program state, WIP, roadmap, support registry,
and active phase packet agree and pass the automated drift check.

## Non-goals

- Implementing exports, OCR, trainer profiles, or new dataset semantics.
- Declaring beta or release readiness.
