## Purpose

Give every later input and output feature a truthful semantic home. Training
family, objective, semantic row, physical container, consumer profile, and
loss/masking MUST remain independent axes. Public APIs and screens MUST NOT
use one “format” value for more than one axis.

Existing v1 objective kinds, row-schema identifiers, bundle paths, and the
optional Aptus profile remain the persisted names. This phase records their
meaning, compatibility, and future-only neighbors. It does not reinterpret
sealed artifacts.
